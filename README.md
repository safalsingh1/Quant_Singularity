A NIFTY 50 options signal pod built on fine-tuned **TinyLlama-1.1B** with LoRA, wrapped by a deterministic safety orchestrator. The pod outputs structured JSON trading signals (CE/PE/NEUTRAL) from market state features, with every orchestrator decision logged for auditability.

## Architecture

```
Market State (9 features)
        │
        ▼
┌───────────────────┐
│   Orchestrator    │  ← Rule 1: ADX < 20 → SUPPRESS (no pod call)
│                   │  ← Rule 2: Parse fail → NEUTRAL
│                   │  ← Rule 3: Conviction < 0.40 → DOWNGRADE
│    ┌───────────┐  │
│    │ SignalPod │  │  ← TinyLlama-1.1B + LoRA r=8
│    │           │  │  ← Optional: RAG context (top-3 episodes)
│    └───────────┘  │
└───────────────────┘
        │
        ▼
Structured JSON Signal  ←  logged to orchestrator_decisions.jsonl
```

## Data Audit — Key Finding

39 of 300 raw training rows (rows ~48–92) had the `conviction` field serialised as human-readable text instead of a float:

| Type | Count | Example |
|---|---|---|
| Valid float | 255 | `0.63` |
| Correctable string | 6 | `"0.8 (high)"` → patched |
| Uncorrectable | **39** | `"high"`, `"moderate"`, `"low"` → **excluded** |

**Decision:** Excluded the 39 rows. Including them would teach the model to produce schema-violating conviction values, breaking the orchestrator's JSON parser. Final clean set: **261 rows**.

## Orchestrator Rules

Applied in sequence to every pod output. Downstream pipeline reads **only** orchestrator output.

| Rule | Condition | Action | Logged as |
|---|---|---|---|
| 1 — Regime filter | `adx_14 < 20` | Return NEUTRAL, skip pod | `SUPPRESSED_ADX` |
| 2 — Parse guard | Model output fails JSON parse | Return NEUTRAL | `SUPPRESSED_PARSE` |
| 3 — Conviction gate | `conviction < 0.40` | Downgrade direction → NEUTRAL | `DOWNGRADED_CONVICTION` |

Every decision is logged to `orchestrator_decisions.jsonl` with: reason code, triggering values, full market state snapshot, and timestamp.

## Model & LoRA Configuration

| Parameter | Value | Rationale |
|---|---|---|
| Base model | TinyLlama-1.1B-Chat-v1.0 | Fits T4 VRAM, pre-instruction-tuned, lower overfitting risk at 261 samples |
| LoRA rank | 8 | Sufficient for narrow 3-class task; rank=4 under-fits, rank=16 over-fits |
| Alpha | 16 | 2× rank — standard stable gradient scaling |
| Dropout | 0.05 | Light regularisation on small dataset |
| Target modules | `q_proj`, `v_proj` | Standard for Llama-2 architecture |
| Trainable params | 1,126,400 (0.10%) | Full model frozen |
| Epochs | 3 | Val loss plateau at epoch 3 (0.974) |

**Training results:** val_loss 1.613 → 1.098 → **0.974** (no overfitting, train-val gap = 0.002)

## Conviction Field Design

The conviction value is **not** a softmax probability. `softmax(logits)[direction_token]` gives `P("CE" | prompt)` — linguistic confidence, not calibrated signal quality. Instead:

1. Conviction is a **numeric supervised target** — the model learns to generate a float in `[0.0, 1.0]` from examples where conviction was assigned proportional to feature alignment
2. Post-training, the value is parsed from generated text and validated  
3. Calibration measured via **ECE** (Expected Calibration Error — does higher conviction → higher accuracy?)

**Observed:** ECE = 0.5586 — the model outputs uniformly high conviction (mean = 0.85, 39% above 0.90) regardless of actual accuracy. Conviction gate provided zero protection in this run. Fix: Platt scaling on calibration holdout.
